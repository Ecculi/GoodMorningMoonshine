# GoodMorningMoonshine
Modern version of Spurgux

Suunnitelma ja päätökset: [DESIGN.md](DESIGN.md)

## Prototyypin ajaminen

1. Asenna [Godot 4.7](https://godotengine.org/download) (tavallinen versio, ei .NET).
2. Avaa Godotissa tämän kansion `project.godot` ja paina F5.

Ohjaus:

| Toiminto | Näppäimistö | Peliohjain | Puhelin |
|---|---|---|---|
| Liiku | nuolet / WASD | ristiohjain / vasen tatti | ohjaussauva (sormi vasempaan alakulmaan) |
| Juokse | suunnan kaksoisnapautus tai Shift + nuoli | kaksoisnapautus tai RB pohjassa | ohjaussauva reunaan asti |
| Lyö / juo / syö | välilyönti, Z tai Enter (lyhyt painallus) | A | iso nappi |
| Heitä käden tavara | sama nappi pohjassa | sama | sama |
| Puhelin auki / kiinni | P tai Tab | Y | puhelinnappi (pieni nappi ison napin yläpuolella) |
| Selaa puhelinta | vasen / oikea | sama | sama |

Ohje: F1 (peliohjaimella Back) avaa ohjeen, jossa on pelin tavoite ja näppäimet; peli odottaa sen ajan.

Debug: avaa ohje (F1) ja paina F12. Vasta sitten toimivat F5 health täyteen, F6 alkoholia +0,1 ‰ joka painalluksella (ei ylärajaa), F7 rahaa +100 €, F8 puhelimen akkua +25 % ja F9 nälkä, kylmä ja väsymys pois, F10 seuraava päivä, ja samat napit näkyvät ruudun vasemmassa reunassa. F12 ohjeessa uudestaan kytkee ne pois.
